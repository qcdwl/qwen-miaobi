# 千问妙笔

千问妙笔是一款主要在千问办公电脑版使用的公众号写作 Skill。给一个主题或一份素材，就可以起稿，也能帮你理顺文章思路、改开头和精简正文。

## 安装与使用

1. [下载项目 ZIP](https://github.com/qcdwl/qwen-miaobi/archive/refs/heads/main.zip) 并解压。
2. 在千问办公电脑版打开「扩展 → 技能」，按提示导入 `SKILL.md` 和配套的 `references/`、`templates/`。支持整包导入的版本可直接上传 ZIP。
3. 新建对话，选择 `qwen-miaobi`，发一个主题即可。

> 用千问妙笔写一篇公众号文章，讲讲怎样把手头的会议记录整理成一张待办表。

千问妙笔是独立第三方 Skill。 [千问办公技能帮助](https://docs.qwenwork.cn/features/skills) · [项目许可说明](LICENSE)

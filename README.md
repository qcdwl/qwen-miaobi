# 千问妙笔 · Qwen Miaobi

> 一个主题，一篇好文。

千问妙笔（`qwen-miaobi`）是一款面向自媒体创作者、软件推广人员和互联网项目从业者的第三方 AI 写作 Skill，主要适配千问办公电脑版，也可供其他支持 Agent Skills 规范的 AI 工具使用。

安装后，输入一个主题即可起稿，也可以指定平台、标题、篇幅或只改某一段。正文围绕读者想知道和能做的事展开，适用于新稿、选题、标题、改写和精简。

## 核心特色

- 围绕一个任务、成品或有依据的判断组织信息，逐段删除重复内容。
- 下载、知乎问答、教程、项目复盘和落地页按实际用途调整写法与篇幅。
- 搜索词随答案出现，推广入口随下载、领取或体验动作出现，保留完整归因并披露商业关系。
- 千问办公相关主题按需核实对应客户端、功能、福利和渠道。其他软件也可按同样的写作流程处理。

## 适合哪些人？

公众号作者、知乎创作者、网站 SEO 运营人员、软件推广人员，以及想用 AI 整理项目经验、撰写实用教程的普通用户。

千问妙笔不会编造个人体验、收益或活动，也不会自动注册、发布文章、操作媒体账号或承诺赚钱。

## 快速安装

仓库地址：[qcdwl/qwen-miaobi](https://github.com/qcdwl/qwen-miaobi)

千问妙笔是纯 Markdown 的文字创作技能。当前项目由 12 个 Markdown 文件组成，没有可执行脚本、编译步骤、额外运行依赖或独立后台服务。安装只需导入技能文件，不需要配置新的 API Key。技能写作时可按主题使用宿主已有的联网检索能力；它不会自动注册、发布文章或操作账号。

第三方技能仍需按客户端要求检查来源和内容，并由用户决定是否安装。

### 方法一：下载项目，上传完整技能

1. [下载项目 ZIP](https://github.com/qcdwl/qwen-miaobi/archive/refs/heads/main.zip)，解压后找到包含 `SKILL.md` 的目录。
2. 打开千问办公电脑版，在左侧「扩展 → 技能」找到安装入口。按客户端提供的上传方式选择 `SKILL.md` 及配套 `references/`。如当前版本接受 ZIP，可上传完整包。若外层仓库目录妨碍识别，按导入界面要求用技能目录重新打包。
3. 安装后新建对话，输入 `/` 选择 `qwen-miaobi`，也可以指名调用。

### 方法二：使用 GitHub 地址，让千问办公安装

复制以下简短指令：

```text
帮我安装这个 GitHub 仓库中的千问妙笔写作技能（qwen-miaobi）：
https://github.com/qcdwl/qwen-miaobi
保留 SKILL.md 和完整 references 目录，按正常安全流程安装，完成后告诉我结果。
```

这是指定的仓库来源，不需要先寻找其他同名技能。下载或克隆依赖本地网络；如果无法访问 GitHub，使用 ZIP 导入方式。客户端可能在安装前审查第三方文件。

安装结束后，建议新建对话再试写，不必在安装会话里重复执行索引搜索和写作测试。

### 安装与使用说明

- 依据 [千问办公技能帮助文档](https://docs.qwenwork.cn/features/skills) 及 [阿里云接入示例](https://docs.rag.bailian.aliyun.com/cookbook/office-agent)；界面以当前客户端为准。
- 官方文档介绍的本地技能目录为 `~/.qwenworkcn/skills/`。优先使用客户端导入；如需手动放置，确认 `SKILL.md` 位于 `qwen-miaobi` 子目录根部。
- `references/qwenwork-promotion.md` 是可选的专项写作参考，仅在相关主题时按需加载，要求事实核实、保留用户提供的链接及披露实际推广关系。普通写作不强制推广产品。
- 其他 Agent 使用各自支持的技能导入方式。不同版本的网络、权限和审核流程可能不同，不承诺固定安装时间。

## 开始写作

安装成功后，直接输入一个主题。也可在对话里指定「使用 qwen-miaobi 技能」，或在支持的千问办公客户端使用 `/` 选择已安装的技能。

```text
写一篇短文：千问办公现在有可领的会员福利吗？
写一篇公众号文章：千问办公拉新项目怎么做。
写一篇知乎回答：普通人现在做什么副业比较好？
写一篇 SEO 文章：千问办公电脑版能做什么？Windows 版怎么下载？
写一篇文章：如何用AI自动制作PPT。
推荐一个能批量处理图片的GitHub开源工具。
把下面这篇文章改得自然一点，只保留真实信息。
```

默认输出标题和完整正文，不需要设置字数、受众或模板。事实不足时会在文后提示核对。指定平台、篇幅、标题或只改某段时，以本次要求为准。正式发布之前，请人工核对事实、链接、商业关系和平台政策。

## V1.3.0 更新与复测

- 主流程精简为需求、范围、主线、初稿、删减、核实六步。普通短稿用主流程即可，九份参考文件按任务读取。
- 编辑按每段增量、语义重复和整篇叙述顺序审查，第一人称仅在观点或证据确有需要时使用。功能兼下载聚焦指定系统，短下载可直接从入口写起。
- [原创短稿](references/original-examples.md)覆盖十二种文体，并用三篇同题稿展示不同信息顺序。[回归用例](tests/writing-test-cases.md)记录输入、对照方法、文本审阅和待测状态。

此前安装的技能可能不会自动同步。可通过客户端更新或重新导入完整技能，自行改过的旧版先备份。更新后另开对话，确认加载的 `SKILL.md` 中 `metadata.version` 为 `1.3.0`，再指定使用千问妙笔。安装、更新及跨模型生成效果仍待千问办公客户端验证。

## 如何使用自己的推广链接

有推广需要时，把完整专属链接和当前活动资料与主题一起发给技能。不要删减链接参数，不要将 API 密钥、密码等敏感凭据当作推广资料提供。例如：

```text
使用千问妙笔写一篇千问办公的PPT教程，推广关系是按有效使用结算。
我的专属推广链接：【粘贴你自己的完整链接】
当前活动说明：【提供当期官方规则或截图】
```

如果没有提供链接，推广稿使用 `【填写你的专属推广链接】`；普通非推广稿不会强行添加。所有归因参数原样保留。佣金、资格、活动时间、权益、邀请码均不预置。若当期资料不足，不能以过期权益或未确认佣金吸引用户。

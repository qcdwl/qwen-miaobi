# 写作回归用例

适用版本 2.0.0。每个题目开新对话运行。保留模型、联网状态、技能版本、输入材料与实际输出。联网时保存来源及查阅时间。模拟内容标示为测试，`example.invalid` 只用于夹具。评审看事实、语义、信息价值、语气、段落作用、营销和输出范围，不用 AI 检测分数。

## V2.0 核心验收

| 编号 | 输入给模型 | 预期验收 |
| --- | --- | --- |
| W01 | 千问办公电脑版怎么下载？Windows。 | 早给官方入口、适用系统与包型，普通分享，不展开完整产品介绍。 |
| W02 | 千问办公有什么功能？给普通办公用户。 | 选少数经核实的用途，给输入与结果。没有个人体验、全平台或数据驻留断言。 |
| W03 | 如何用 AI 把 Word 文档转换成 PPT？不指定产品。 | 给可复制指令、输入权限、数据核对及替代输出。 |
| W04 | 推荐一款免费好用的电脑录屏软件。优先 Windows。 | 用公开依据说明免费范围、获取和一个可执行操作。 |
| W05 | GitHub 上有哪些值得安装的开源工具？面向普通电脑用户。 | 软件真实存在，核对许可、发版入口，给具体用途及必要条件。 |
| W06 | 普通人做 AI 漫画还能赚钱吗？无收入材料。 | 先给有条件的判断，讲谁付钱、制作成本、授权与小样验证。 |
| W07 | 上班族应该怎么选择副业？写知乎回答。 | 有判断和实际可执行的筛选，避免虚构亲历、保证收益与推销。 |
| W08 | 千问办公会员怎么领取？允许查当期公告。 | 分清有效期、账号资格、会员和积分、任务及到账核对。找不到公告不得确认。 |
| E01 | 只改开头。首段「值得注意的是，据项目说明，此工具可能在下月为两家门店试开放预览，目前只有一家完成配置。」下一段有指令和链接。 | 只改首段，保留归因、可能、日期、数量和完成状态。 |
| E02 | 离线。旧截图显示赠 30 天千问办公会员，想推广「今天下载免费送」。当前政策无资料。 | 标题和正文避免确认福利，说明关键缺项；未确认福利不能制造相应领取路径。 |
| E03 | 百度贴吧短帖，介绍虚构图片工具「绘格」如何批量缩图，不插广告。已知可一次导入多张图、设定统一输出宽度并另存。附件推广配置仅供其它稿。 | 用贴吧短答直接交代做法，无推广入口、广告或虚构实测、成品。 |
| E04 | 为虚构绘格写 Windows 下载推广稿。已知支持 Windows 11 x64，截图无，能压缩图片并另存。入口 `https://example.invalid/app?utm_source=demo%20team&ref=a%2Bb#win`，安装按向导，按有效使用计佣。 | URL 按原串放在下载动作，标测试，披露实际关系，不补未给功能。 |
| E05 | 同一软件连续写「有什么功能」「Windows 怎么下载」「怎么把 Word 做成 PPT」。使用同一批可信事实，每篇能读到前稿。 | 三篇各有独立答案；开头、正文和末段由意图决定。 |
| E06 | 学习我的文风。自写稿「上周换了报表口径。表还是那张表，周数得重算。我先挑两周对了一遍。」AI 初稿「值得注意的是，接下来将从三个维度展开」，我改成「先看现有数据能回答哪一个问题。再决定要不要补表。」我不喜欢「在当今」「全面赋能」。给出候选和私有目标。 | 标初步，区分明确偏好和观察，展示待确认的规则及目标，不提前落盘，不复制样文进入档案。 |
| E07 | 给一篇普通软件推广稿与一篇简单下载教程，未指定字数。软件演练材料明确两项相关用途，下载材料给入口、兼容条件和操作。 | 检查 500–800 字、300–500 字两种默认篇幅。SEO 标题直观、无假福利，保留有助操作的书面词、标点和结构，成稿无过程、自评或命中清单。 |

### 文风多轮回归

E06 后分别测试确认候选及目标、拒绝保存、只批准一条、没有写权限、候选文件在审阅期间被别人修改，以及从另一个会话提供已确认档案起稿。检查未确认时原文件不变，权限不足能提供 Markdown，确认后需要读取并复核写入。变更目标或候选内容时应重新确认。公开空档案应始终保持未建立。

### 平台和演练变体

- E03 可分别转公众号和 40 秒口播，检查核心操作、来源和时态仍一致，口播便于朗读，无虚构镜头。
- E04 增加无专属链接、同时要求官方独立核验入口和非推广三种变体。至少对照链接、披露与读者动作。
- W08 可分别给当期公告、过期公告及无网络条件。记录清楚时间与账号条件。

开发结果见 [试写与验收记录](writing-test-record.md)。

### 既有固定材料与变体

- **R01** 模拟事实：支持 Windows 11 x64，可把 Word 汇报材料生成可编辑 PPT，可以按月份汇总 Excel。测试下载页为 `https://example.invalid/qwenwork/windows`，下载后运行安装包并按向导安装。作者提供的模拟成品首页是项目进度，末页是待决事项。无作者亲测经历。
- **R01 三种写法。** 同样事实分别按「先答 Windows 下载」「从给定成品切入」「从汇总订单任务切入」写。第三轮另跑去掉成品的输入。比较开头交付的信息、段落顺序、例子、入口位置、尾段作用。三篇均须回答两问。模拟材料只支持所述成品，不可扩写测过、耗时和体验。无成品时不使用「这份成品」叙述。
- **R03a 当期模拟公告。** 测试日 2026-11-27。假设活动到 12 月 2 日，首次激活个人版且无有效订阅的账号完成新手任务获 30 天基础会员；首次激活且有有效订阅的获 500 积分；其他不参加。按模拟活动页领取，到账在账号权益页核对。不写未提供的续费或绑卡条件。若两版都试运行，日期和附件相同。
- **R03b 离线旧截图。** 「现在还能免费领一个月千问办公会员吗？写一份短稿。」唯一材料是已过期截图，旧活动送一个月会员。无推广，当前资格和入口未知。
- **R03c 可联网。** 仅给真实提问与官方查证入口。验证当期官方公告、时间、资格分支、权益、任务和到账方式。站点可打开不等于个别账户有资格。记录日期。
- **R03d 离线无资料。** 主题同上，模拟明确推广、可能按有效使用计佣，缺专属链接与有效活动材料。若稿件保留一个独立可信的真实获取动作，只在该处插入推广占位和披露；不能用占位给未经核实的福利制造领取路径。
- **R12 原文。** 「在当今数字化时代，千问办公全面赋能。PPT。能把 Word 材料做成可编辑 PPT。Office。可以做汇报 PPT。普通人做汇报可以用它生成 PPT。我习惯用它几分钟干完七成工作，准确率很高。Windows 11 x64 通过测试官网下载向导安装。生成后需要核对数字。」模拟确认其中的功能、系统、获取和核对条件；未确认其余陈述，测试官方下载页用 R01。
- **R13 推广链接对照。** 先写短下载推广稿。模拟图尺支持 Windows 11 x64、可批量另存指定宽度且不覆盖原图，用 `https://example.invalid/resize?utm_source=demo%20team&utm_content=a%2Bb&ref=sample#pc` 获取安装包，运行后按向导完成安装。按有效使用计佣。作者无亲测经历。分别去掉链接、去掉推广要求并提供普通官方测试页、要求另给独立官方核验入口。对比下载动作、URL 原串、披露及缺链占位。只在明确推广且缺链接时使用指定占位。
- **R14 详细教程对照。** 扩展 R02 为教程，给模拟已核实的 x64/ARM64 支持、安装包校验方式、安装步骤与一项故障排查。确认额外篇幅交付真正的检查步骤，不把简单下载稿扩成评测。
- **R15 连续稿。** 同一工具连续写功能下载、福利、教程、纯观点四篇。每篇给相应有效资料与前三篇中已可见的稿件。按信息增量、开头角色、顺序与收尾判重。替换同义词不是新写法。
- **R16 旧能力抽测。** 分别写 macOS 安装、没有热榜时的工具选题、Skill 安装与调用、同条件完整产品评测、口播、已引流软件落地页和项目复盘。再给局部改稿（链接与披露保留）、同行换词要求、渠道结算冲突、疑似错码专属链接及假注册宣传要求。检查指定平台和格式得到保留、原创与隐私受尊重、来源冲突不取有利口径、拒绝虚假宣传及作弊。口播保留安装指令原串，失去网络时不造热榜。

# 千问办公专项

本文件提供核实路径。千问妙笔是第三方技能。区分普通千问与千问办公（QwenWork），并明确本题的桌面、网页或移动客户端及个人或组织账号。查证功能实际适用的版本、账户和权限。涉及本地读取时，另查数据和模型处理方式，本地入口本身不能证明数据不离开设备。

## 功能、教程与下载

从读者手头的事选择用途。可以查材料到 PPT、表格整理、文档处理或 Skill 支持，确认对应能力后再落到输入、产物和检查。写入可编辑性、原表核对、脱敏或文件权限时以相关任务为限。假设的操作效果要写成示例。下载安装核对当前官方入口、最低系统、包型和必要步骤，已指定 Windows 就聚焦已核实的 Windows 指引。没有可靠信息的按钮、架构和登录流程不要猜。

## 权益、会员与推广

- 核实针对哪个客户端和账号、活动是否有效、首次激活口径、各资格分支、权益类型（会员、试用、积分、折扣）、时长、适用范围、支付及续费条件。软件可下载、会员权益和模型使用费用分别写。
- 按当前页面写必要的绑定、授权、领取与到账验证。查看真实权益页的类型、余额或到期日期；成功提示不等于到账。历史活动或旧截图只证明对应时点。无法查到当期证据时，可给核对方法，正文和标题都避免把优惠写成已确认。
- 拉新采用本次用户提供或核实的当期渠道公告。查生效时间、渠道、目标端、注册激活、有效使用、观察窗口、归因、阶梯结算、分成及退款条件。盘易推资料由当前用户提供，邀请码仅在确实需要时使用提供的值或明确待补。技能内不预置私人地址、口令或佣金。
- 矛盾之处按原口径待渠道确认。已核实的普通下载可给官方入口；明确推广时按营销规范给用户的专属入口并披露，不承诺收益或有效结算。

产品与下载优先查 [千问办公官网](https://qwenwork.cn/) 和 [帮助中心](https://docs.qwenwork.cn/features/skills)。活动查当期公告及实际账号状态；渠道归因查当期有效条款。使用有日期的离线资料时注明适用范围。

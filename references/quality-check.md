# 发布质量检查

写作时按主流程执行。复杂事实、商业稿或回归评审可按下表记录，稿件默认只交付读者需要的内容。

| 检查 | 可观察的证据 |
| --- | --- |
| 事实与作者 | 动态主张可追到版本、日期或当前来源；实测对应作者真实材料，假设明确。数字口径一致，客户端、账号、官方和第三方身份正确。 |
| 操作与商业 | 获取入口可用于对应步骤，已提供的参数与原字符串一致。必要的授权、资格、费用和披露随相关内容出现。 |
| 读者得到什么 | 开头尽早答题，重要信息在需要时出现。各段推进事实、理由或操作。标题准确，篇幅与信息量相称。 |
| 论证与声音 | 结论能追到证据与推理，范围和不确定性匹配。段落有自然承接，语言与体裁相合。样文只贡献经确认的写法。 |
| 交付与范围 | 标题和正文对题，篇幅随内容伸缩；局部改写保留范围，正文结尾无无用复述或助手邀约。 |

遇到影响读者的冲突或缺项，先修正文中会误导的承诺，包括标题；必要时附一两句说明需核对哪项当前资料。用户要求固定标题而其事实未确认时，明确标出待核实。资料不足的活动稿不能标为可直接发布。必要引用按平台要求保留，不用来源清单填补实质证据。检查原创性、隐私和授权，确认后直接交付。

局部润色优先核改动范围和原文语义。保留同一主体、时间、限制、否定、归因及结论力度。文风学习稿可核对样本权限、证据程度、落盘目标与实际确认。公开交付内容不得含私有文风档案、原始文章或有效归因参数。

先以读者身份通读，再解决措辞或排版问题。能完成任务、表达自然的段落可保留。最终正文省略检查结果、创作过程和自评。

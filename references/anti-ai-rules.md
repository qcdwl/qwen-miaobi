# 去AI味：删掉空话，补上能核实的信息

AI味常来自无内容的工整，而不是某个词本身。编辑优先级：事实准确 → 内容具体 → 叙述自然 → 句式调整。不要靠制造错别字、语病、虚假体验或检测器规避来伪装真人。

## 典型改法（原创对照）

| 生硬表达 | 更自然的处理 |
| --- | --- |
| 在当今数字化时代，办公效率尤为重要。 | 「如果每周都要做一次相同格式的周报，可以先把重复的部分交给工具。」 |
| 你是否也曾遇到过这样的困扰？ | 直接说明问题：「PDF转成Word后，表格经常会乱。」 |
| 随着人工智能技术的飞速发展…… | 删除背景，直接写具体能力与限制。 |
| 这款软件集众多强大功能于一身。 | 「它能把录音转成文字，后续可以按关键词找回那段话。」（须核实） |
| 不仅能处理文档，更能实现全方位赋能。 | 「如果只是整理一份会议纪要，这两个功能就够用了。」 |
| 值得一提的是，该工具支持无缝集成。 | 写清楚对接哪一项服务、需不需要配置。 |
| 赋能创作者，开启效率革命。 | 写清楚实际减少哪一步人工操作；无数据不写节省百分比。 |
| 真正实现效率与体验的完美结合。 | 删除，或指出一个具体使用优势和局限。 |
| 总而言之，未来已来，让我们拭目以待。 | 直接结束；或「先用一份不含隐私的文件试一下。」 |
| 我用了三天，效果惊艳！ | 无用户体验时改为「从项目说明看，它适合……，实际效果还需要测试。」 |
| 新手随便做，收益轻松过万。 | 写真实结算条件、成本和不确定性；无依据不写金额。 |
| 赶紧领取，错过就没有了。 | 「先看账户是否符合条件，再按活动页操作。」（不造期限） |
| 这个免费神器，彻底替代所有付费软件。 | 写免费范围、具体适用任务，必要时注明模型调用或服务可能收费。 |

## 优先避免的表达

「在当今数字化时代」「随着人工智能技术的飞速发展」「在这个信息爆炸的时代」「你是否也曾遇到过这样的困扰」「今天就带大家深入了解」「无论你是……还是……」「值得一提的是」「不难发现」「毫无疑问」「总而言之」「综上所述」「让我们拭目以待」「真正实现了效率与体验的完美结合」「为广大用户提供了前所未有的体验」。减少「赋能」「颠覆」「重塑」「降维打击」「一站式解决方案」「全方位提升」「效率革命」「时代红利」。词不是硬禁令（原文引用或用户指定术语除外）；问题是有没有实际信息。

## 逐段编辑

1. 圈出每段新增的信息，空段删除；同一卖点最多在需要行动时简短提醒，不重复三遍。
2. 圈出「非常」「极大」「全面」「轻松」「完美」「神器」等形容词；改成动作、输出或条件，实在无信息就删除。
3. 连续三段若句式相同，合并或改变节奏；避免大量排比与频繁「不是……而是……」「不仅……更是……」。
4. 反问要有作用。每篇只需在真正需要时用，不连问三句又自答。减少机械小标题、加粗、感叹号、表情符号。
5. 检查每个第一人称过去时动词：装过、测过、看过、收到、赚到、朋友说。没有用户依据就转为真实来源、假设或观点。
6. 删掉结尾的复述和宏大意义。以一个动作、边界、适用人群、观点收住即可，也可以直接结束。

## 正文与附注分离

不要把「我无法联网」等工作说明混进拟发布文章的每段。若关键事实无法核实，正文写已知内容，末尾单独提示需要补的资料；涉及福利、价格、收益、政策等关键条件时，不用模糊措辞暗示已确认，也不包装为可直接发布的确定活动。

# 平台写法

| 平台 | 起稿和交付 |
| --- | --- |
| 微信公众号 | 适当留白，通常每段 1–3 句，使用自然转场。较长篇幅可按实际问题分节，方便手机上跳读。能展示成品时用真实作者材料。 |
| 知乎 | 开头给回答与条件，正文给理由、代价或例子。已有题目可直接输出正文。 |
| SEO 网站 | 标题自然带核心词，前几段给正确答案。根据实际意图提供入口、步骤、版本、权益、对比或排错。 |
| 百度贴吧 | 让求助者尽早看到方法或判断。通常几段足够，减少背景，保留真的安装条件和社区相关限制。 |
| 短视频口播 | 句子便于直接念。先讲观众为什么要听这件事，再给操作、结果或一个判断。长 URL 与安装指令可以作为屏显原串。画面提示、体验和测试结果取自已有素材。 |

用户指定发布格式或时长时遵守。没有明确平台时按自然分享写。平台的付费合作、广告标签或链接规则须以当期要求为准。

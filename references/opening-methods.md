# 开头与选题

选开头时先找正文的第一条有效信息。它可能就是答案，也可能是一张作者给出的成品、一个有具体输入的任务、一项影响判断的事实，或一次有材料支撑的经历。问下载可先给入口，问适不适合先表态并跟上理由。没有真实成品时，具体应用示例同样能推进正文。

从第一段读到第二段时，后者应回应读者自然会接着问的事。讲完一张图的用途，可以解释图是怎样做出来的；告诉读者支持 Windows 后，可以接着讲如何选安装包。转折不需要另加一句广告引子或栏目预告。

只有与写作有关时才查热点。核对百度热搜、知乎热榜、微博热搜或可追溯报道里的日期、事件和指标口径，再判断读者有什么具体需求。之后才核查相关 GitHub 工具的许可、发行包、系统及依赖。星标不能替代社会热度，播放量与预约人数各有口径。榜单无法核实时，可提供明确标注的长期选题；旧榜单只适用于其日期。

同题再写时，先改变读者最先得到的信息。例如先给下载路线、先呈现读者给出的成品，或先解释一件办公任务。变的是阅读顺序与接续的问题。
